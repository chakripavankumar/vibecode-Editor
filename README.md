🚀 Vibecode Editor

Vibecode Editor is a full-stack, browser-based IDE built with Next.js and Monaco Editor. It brings code editing, AI assistance, project templates, terminal access, and real-time code execution into a single developer-focused workspace.

Built with Next.js 15, React 19, Tailwind CSS v4, and a modern AI-first toolchain.

✨ Features

* 🔐 OAuth Authentication — Sign in with Google or GitHub using NextAuth.
* 🎨 Modern UI — Clean developer experience powered by Tailwind CSS & ShadCN UI.
* 🌗 Dark / Light Mode — Seamless theme switching.
* 🧱 Project Templates — React, Next.js, Express, Hono, Vue, and Angular.
* 🗂️ File Explorer — Create, rename, delete, and organise files and folders.
* 🖊️ Monaco Editor — Syntax highlighting, formatting, keybindings, and AI autocomplete.
* ⚙️ WebContainers — Run frontend and backend applications directly in the browser.

🛠️ Tech Stack

Frontend: Next.js 15 · React 19 · Tailwind CSS v4 · ShadCN UI
Editor: Monaco Editor
Runtime: WebContainers
AI: Ollama
Authentication: NextAuth
Terminal: xterm.js

🎯 Vision

Vibecode Editor aims to provide a complete, AI-assisted development environment that runs entirely in the browser, making it easier to build, experiment, and learn without leaving your workspace.
